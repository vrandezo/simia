Simia has been entirely redone. The saddest part is that I moved it away from [Semantic MediaWiki](https://www.semantic-mediawiki.org), which is really painful. This blog has been running on Semantic MediaWiki since 2007, for almost two decades. But in the last few years, massive bot activity has made it harder and harder to keep the site running. I didn't want to go with CloudFlare, and I spend quite some time in improving the performance of the blog, and it worked, some of the time.

Now I switched over to a static Website, edited with PagesCMS, generated with Hugo, stored in GitHub, and hosted from a Google VM. Let's see how this will work.

I will write a bit more about the technology of this site, how it used to work, how it works now, in due time, but for now, I actually just want to try out if I got PagesCMS properly connected.
