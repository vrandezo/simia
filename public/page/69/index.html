Semantic MediaWiki

Semantic MediaWiki is an extension to MediaWiki. It enables users to type the links between pages, and to add attribute-value pairs to a page. Based on this it allows a multitude of novel ways to access the information within the wiki. It is an open source project with the main contributors being Markus Krötzsch, S Page, and Denny. Website http://semantic-mediawiki.org
